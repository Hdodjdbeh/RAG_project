# Reply Generator — Генерация ответов на отзывы Wildberries

Сервис для автоматической генерации ответов на отзывы на основе базы правил с использованием гибридного поиска (семантический + ключевые слова) и YandexGPT.

## Архитектура пайплайна
Отзыв пользователя
↓
[API эндпоинт]
↓
[RAG Engine] ←─────────────────┐
↓ │
[Hybrid Retriever] │
├─ Векторный поиск (ChromaDB) │
├─ BM25 (ключевые слова) │
└─ Комбинирование результатов │
↓ │
[Найденные правила] │
↓ │
[Формирование промпта] │
↓ │
[YandexGPT Client] │
↓ │
[Пост-обработка ответа] │
↓ │
[Готовый ответ] ───────────────┘


## Логика обработки отзывов

### 1. Получение отзыва

Сервис принимает отзыв через REST API:
- `POST /generate` — один отзыв
- `POST /generate/batch` — пакетная обработка

**Входные данные:**
```json
{
  "text": "Товар пришел сломанным, хочу вернуть деньги",
  "rating": 1
}
```

# 2. Гибридный поиск правил (Hybrid Retriever)

Сервис ищет релевантные правила/инструкции для ответа, используя два метода одновременно:
Метод	Что делает	Вес (alpha=0.6)
Семантический поиск	Находит правила со схожим смыслом через эмбеддинги (ChromaDB)	60%
BM25	Находит правила по ключевым словам (возврат, брак, доставка)	40%

Алгоритм:

    Преобразуем отзыв в вектор (EmbeddingService)

    Ищем в ChromaDB топ-2k правил по семантической близости

    Токенизируем отзыв и ищем через BM25 по всем документам

    Нормализуем оценки (0..1)

    Комбинируем: combined_score = 0.6 * vector_score + 0.4 * bm25_score

    Возвращаем топ-3 правила с порогом схожести >0.5

Пример найденных правил:
```json
[
  {
    "text": "При получении бракованного товара клиент может оформить возврат...",
    "category": "returns",
    "tone": "official",
    "similarity": 0.87
  }
]
```
# 3. Формирование промпта (RAG Engine)

На основе найденных правил и отзыва формируется запрос к LLM:

System промпт (роль ассистента):
Ты - оператор службы поддержки Wildberries.
Твоя задача - отвечать на отзывы клиентов, соблюдая следующие принципы:
1. Будь вежливым и эмпатичным
2. Отвечай по существу, используя предоставленные правила
3. Если проблема описана в отзыве - предложи решение
4. Не обещай того, что не можешь выполнить
5. Ответ должен быть на русском языке
6. Благодари за положительные отзывы
7. Для негативных отзывов приноси извинения и предлагай помощь

User сообщение содержит:

    Оценку отзыва (если есть)

    Текст отзыва

    Найденные правила (контекст)

    Инструкции по формированию ответа

# 4. Генерация ответа (YandexGPT)

Клиент отправляет запрос в YandexGPT API:

    Модель: YandexGPT Lite

    Temperature: 0.85 (креативность)

    Max tokens: 500

    Retry policy: 3 попытки с экспоненциальной задержкой

# 5. Пост-обработка

Сгенерированный ответ очищается:

    Удаление лишних пробелов и переносов

    Удаление префиксов ("Ответ:", "Оператор:")

    Обрезание до 500 символов

# 6. Fallback механизм

Если поиск не нашел правил или LLM вернула ошибку:

- 4-5 звезд	"Благодарим вас за высокую оценку! Мы рады, что вам понравился товар. Спасибо, что выбираете Wildberries!"
- 1-2 звезды	"Приносим извинения за доставленные неудобства. Пожалуйста, свяжитесь с нашей службой поддержки, и мы поможем решить вашу проблему."
- Нет рейтинга	"Спасибо за ваш отзыв! Каждое мнение важно для нас. Если у вас есть вопросы или предложения, пожалуйста, обратитесь в службу поддержки Wildberries."

# API эндпоинты

## Метод	Эндпоинт	Описание

### POST	/generate	Генерация ответа на один отзыв

### POST	/generate/batch	Пакетная генерация

### GET	/health	Проверка состояния компонентов

### GET	/metrics	Prometheus метрики

### GET	/stats	Статистика системы

## Пример запроса: 
```
curl -X POST http://localhost:8000/generate \
  -H "Content-Type: application/json" \
  -d '{
    "text": "Товар пришел с браком, хочу обменять",
    "rating": 1
  }'
```

## Пример ответа
```json
{
  "reply_text": "Здравствуйте! Приносим извинения за бракованный товар. Вы можете оформить обмен в личном кабинете в разделе 'Возвраты' в течение 14 дней...",
  "used_rules": [
    {
      "id": "rule_42",
      "similarity": 0.87,
      "category": "returns"
    }
  ],
  "confidence": 0.85,
  "tone": "official",
  "is_fallback": false,
  "generation_time_ms": 1240.5
}
```

# Метрики (Prometheus)
### Метрика	Тип	Описание
- #### reply_generator_requests_total	- Counter - Общее количество запросов с метками method, endpoint, status
- #### reply_generator_generation_seconds - Histogram	- Время генерации ответа в секундах
- #### reply_generator_rules_retrieved	- Histogram	- Количество найденных правил на запрос
- #### reply_generator_confidence	- Histogram	- Уверенность в сгенерированном ответе (0-1)
